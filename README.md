# Velora Nail & Beauty

Kurgusal bir güzellik ve tırnak stüdyosu için demo web sitesi. Randevu formu,
hizmet/fiyat listesi, galeri, iletişim bilgileri ve tarayıcı içi örnek yönetim
paneli içerir. İletişim bilgileri ve yönetim panelindeki randevular demo verisidir.

## Geliştirme

```sh
bun run dev
```

Testleri çalıştırmak için `bun run test` komutunu kullanın.
