# Velora Nail & Beauty

Velora Nail & Beauty, tırnak ve güzellik stüdyosu için hazırlanmış bir tanıtım ve randevu sitesi demosudur. Hizmet ve fiyat listesi, çalışma örnekleri galerisi, iletişim bilgileri ve randevu formu sunar. Demo yönetim arayüzünde hizmetler ve örnek randevular görüntülenebilir.

Stüdyo ve iletişim bilgileri ile randevu kayıtları örnek veridir; site gerçek bir rezervasyon veya müşteri yönetim hizmetine bağlı değildir.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.
